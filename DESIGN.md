## Brand & Style

This design system delivers a mission-critical, high-cognitive-throughput interface engineered for synthetic intelligence monitoring and rapid command execution. Inspired by advanced holographic heads-up displays, the visual language balances cinematic high-tech immersion with absolute operational precision.

### Aesthetic Foundation
- **Holographic Glassmorphism**: Translucent obsidian surfaces layered over deep spatial canvas depths, featuring acute backdrop blurs and luminous diffraction borders.
- **Cybernetic Minimalism**: High functional density without decorative noise. Every HUD bracket, coordinate axis, reticle line, and telemetry tick represents verified computational data.
- **Optical Luminescence**: Focused neon emissions simulate self-illuminating projection glass, utilizing additive cyan luminescence, critical gold overrides, and stable telemetry greens.

### Target Atmosphere
The interface evokes hyper-competence, omniscience, and razor-sharp clarity. It projects the sensation of standing inside a state-of-the-art holographic lab—tactile, hyper-responsive, and relentlessly precise.

## Colors

The color palette operates as an active photonic spectrum against a void canvas, utilizing contrast ratios engineered for instant situational awareness under high cognitive load.

### Core Swatches
- **Primary (`#00f0ff`) — Electric Cyan**: System operational state, active tracking matrices, quantum telemetry indicators, interactive components, and primary energy glow.
- **Secondary (`#f59e0b`) — Stark Amber / Solar Flare**: Critical priority warnings, AI neural subroutines, computational spikes, override actions, and auxiliary tactical vectors.
- **Tertiary (`#10b981`) — Synthetic Emerald**: Environmental telemetry, bio-sync confirmations, structural integrity metrics, and real-time processing stability.
- **Neutral Canvas (`#030712`) — Obsidian Void**: Deepest absorption field, accompanied by peripheral shades `#050b14` (holographic glass plate) and `#02040a` (pure deep space baseline).

### Functional Color Strategy
1. **Luminescent Accents**: Use neon glows via layered box shadows and drop shadows (`rgba(0, 240, 255, 0.45)`) sparingly to draw ocular focus to real-time anomalies or active voice-synthesis waveforms.
2. **Glass Tints**: Substrates use fractional opacity cyan and navy blends (`rgba(5, 11, 20, 0.72)`) paired with ultra-thin holographic lines (`rgba(0, 240, 255, 0.2)` to `rgba(0, 240, 255, 0.4)`).
3. **Muted Telemetry**: Passive values, grid marks, and structural framing drop back to muted cyan-steels (`#1e3a47` and `#0e222d`).

## Typography

The typographic hierarchy juxtaposes hyper-engineered display titling with ultra-legible analytical code.

### Font System Architecture
- **Headlines (`Space Grotesk`)**: Geometric, structural, and angular. Conveys cutting-edge computational power. Rendered primarily in uppercase for titles, telemetry headers, and tactical modes.
- **Data & Readouts (`JetBrains Mono`)**: Monospaced engineering core. Retains micro-scale optical legibility across high-density numeric matrices, live coordinate vectors, timestamp logs, and memory allocation counters.
- **Narrative & System Synthesis (`Manrope`)**: Balanced, neutral modern sans used for fluid contextual AI responses, situational briefs, and complex conversational outputs.

### Typographic Effects
- Monospaced labels feature extended character tracking (`0.12em`–`0.16em`) to emulate instrument panel readouts.
- High-priority metric headers integrate a subtle neon glow via CSS `text-shadow: 0 0 12px rgba(0, 240, 255, 0.4)`.

## Layout & Spacing

The layout model is anchored to a dual-layer spatial coordinate system designed for high-density command modules.

### Grid & Structure
- **Desktop (1440px+)**: 12-column dynamic HUD matrix. Content utilizes full viewport height (`100vh`) with peripheral system brackets, telemetry rails flanking left and right, and an active circular nexus/core center module.
- **Tablet (768px - 1439px)**: 8-column adaptive grid. Telemetry rails fold into collapse-trigger side panels; primary telemetry dials shift to secondary header ribbons.
- **Mobile (Under 768px)**: 4-column fluid stack. Peripheral brackets consolidate into minimal top/bottom status bars. Nested holographic gauges transform into horizontal swipeable modules.

### Rhythm & Alignment
- Strict 8-point structural rhythm with 4-point micro-increments (`0.25rem`) for monospaced status alignments.
- Panels lock into an internal coordinate matrix where structural dividers and laser reticles terminate at precise layout intersections.

## Elevation & Depth

Visual depth is achieved through optical refraction and light emission rather than realistic drop shadows.

### Holographic Layering Architecture
- **Base Canvas (Level 0)**: Void absorption field `#030712` overlaid with a radial background gradient simulating the glow of a central computational core (`radial-gradient(circle at 50% 50%, rgba(0, 240, 255, 0.04) 0%, transparent 70%)`).
- **Telemetry Mesh (Level 1)**: Vector coordinate lines, latitude markers, and subtle static dot matrices positioned with 10% opacity cyan strokes.
- **Holographic Panels (Level 2)**: Translucent glass tiles with `backdrop-filter: blur(16px) saturate(140%)`, background tint `rgba(5, 11, 20, 0.65)`, and borders composed of 1px gradient strokes: `linear-gradient(135deg, rgba(0, 240, 255, 0.35) 0%, rgba(0, 240, 255, 0.05) 100%)`.
- **Command Floating Layer (Level 3)**: Active focus states, modal tactical dialogs, and dynamic orbital widgets. Backed by `backdrop-filter: blur(24px)` with outer perimeter glow: `box-shadow: 0 0 24px rgba(0, 240, 255, 0.18), inset 0 0 12px rgba(0, 240, 255, 0.1)`.
- **Tactical Critical (Level 4)**: Overrides, amber alerts, and critical breach warnings. Emits an intense pulsating amber aura: `box-shadow: 0 0 32px rgba(245, 158, 11, 0.35), inset 0 0 16px rgba(245, 158, 11, 0.15)`.

## Shapes

The geometric architecture utilizes an industrial, hard-edged aesthetic (`roundedness: 0`). Curved radii are avoided in favor of crisp, engineered angles and chamfered surfaces.

### Shape Form Factors
- **Orthogonal Geometry**: Windows, telemetry modules, cards, and input slots are cut at absolute 90° right angles to evoke military-grade electronic glass.
- **Chamfered Cuts (45° Clipping)**: Strategic container corners and button endpoints feature 6px to 12px diagonal chamfers (`clip-path: polygon(...)`) simulating reinforced armored HUD visors and microchips.
- **Arc & Circular Primitives**: Pure circular geometries are reserved exclusively for radial core monitors, rotating gyroscopes, targeting reticles, and arc reactor-inspired telemetry nodes.

## Components

### Buttons & Tactical Triggers
- **Primary Action**: Chamfered edge polygon, translucent cyan background (`rgba(0, 240, 255, 0.15)`), 1px solid `#00f0ff` border, text styled with `label-lg` uppercase cyan. Hover triggers a bright cyan background bloom (`rgba(0, 240, 255, 0.35)`) and `box-shadow: 0 0 16px rgba(0, 240, 255, 0.5)`.
- **Secondary / Ghost Trigger**: Pure transparent glass with dashed corner indicators (`border: 1px dashed rgba(0, 240, 255, 0.3)`). Fills on hover with micro-audio feedback visual wave.
- **Destructive / Override**: Chamfered border with amber stroke (`#f59e0b`), gold internal glow, and high-frequency scanline animation across the button surface.

### Chips & Status Indicators
- **Telemetry Chip**: Encased in monospaced mini-brackets `[ SYS // OK ]`, sized to `label-sm`.
- **Active State**: Solid tertiary emerald pill-bracket with breathing dot indicator (`animation: pulse 2s infinite`).
- **Telemetry Alert**: Neon amber badge with animated horizontal striped background simulating real-time frequency interference.

### Input Fields & Terminal Consoles
- **HUD Command Line**: Single bottom border of 1px solid `rgba(0, 240, 255, 0.4)` with an offset cyan corner caret. Focus state elevates bottom line to a glowing cyan bar with dynamic terminal prompt cursor `_` blinking at 1Hz.
- **Background**: `rgba(2, 4, 10, 0.85)` with micro-grid scanlines overlaid via CSS SVG background data-uri.

### Cards & Tactical Panels
- **HUD Slate**: Glass container framed with decorative exterior corner crosshairs (`+`) at all four corners. Top header bar contains hardware-address styled tracking text (`SECTOR 04 // PROTOCOL ACTIVE`).
- **Surface**: Translucent obsidian with high-blur backdrop filter (`blur(16px)`).
- **Sub-divider**: 1px linear gradient lines that taper off from `rgba(0, 240, 255, 0.3)` to transparent.

### Checkboxes & Binary Selectors
- **Checkbox**: Precise 14px square box with sharp corners, 1px border of `rgba(0, 240, 255, 0.4)`. Checked state displays a glowing cyan micro-diamond or targeting reticle dot in the center with additive glow.
- **Toggle Switch**: Dual-state horizontal slide rail with an angular rectangular thumb that switches between `#1e3a47` (offline) and glowing `#00f0ff` (online).

### Specialized HUD Modules
- **Radial Arc Reactor Gauge**: Concentric circular SVG dials with segmented dash arrays (`stroke-dasharray`), variable rotational speeds, and central telemetry counters displaying numeric output in `Space Grotesk`.
- **Targeting Reticle**: Concentric broken circles with cardinal ticks and corner brackets that track active viewport coordinates on cursor movement.
