# Skill: Modern Frontend Architecture & Tailwind CSS
keywords: [frontend, html, css, tailwind, ui, interface, responsive, javascript]

## 1. Semantic Structure & Clean Layout
- Use semantic HTML5: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
- Responsive design via Tailwind CSS: mobile-first breakpoints (`sm:`, `md:`, `lg:`, `xl:`).
- Always include `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.

## 2. Interactive UX & Vanilla JS
- Clean, modular JavaScript without bulky library bloat unless explicitly needed.
- Toast notifications or accessible modals for user feedback on actions (success, error, loading).
- Proper input validation with clean user-facing error states.
- Clean typography hierarchy and accessible color contrast ratios.
